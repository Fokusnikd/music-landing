# «Ля минор» — демо-лендинг

Демо-проект для портфолио: лендинг детской музыкальной школы. Школа вымышленная, педагоги, цены и отзывы придуманы, заявки никуда не отправляются.

Идея: minor по-английски — «несовершеннолетний». Все ученики школы — миноры от 4 до 17 лет, а в 18 «переходят в мажор».

## Интерактив и моушн

- Первый экран — живое пианино на две октавы: играется мышкой, пальцем или с клавиатуры (физические клавиши, работает и в русской раскладке). Ноты разлетаются цветными значками, клавиша «ля» отвечает «440 Гц — это мы»
- Кнопки «В миноре» / «В мажоре» играют «Во поле берёза стояла»: мелодии отличаются одной нотой, и это слышно
- Звук — Web Audio-сэмплер на записях настоящих инструментов (рояль Salamander, гитара, скрипка, укулеле, хор; 2,6 МБ, грузятся лениво, недостающие ноты — транспонированием ближайшего сэмпла). Ударные синтезируются, и синтез же подстраховывает, пока сэмплы не загрузились или если сеть недоступна. Авторы и лицензии — `public/samples/CREDITS.txt` и в подвале сайта
- «Сколько лет вашему минору?» — ползунок возраста переключает программу и считает, сколько лет осталось до мажора
- «Первый урок как гамма» — по нотному стану при прокрутке едет плейхед и закрашивает ноты ля-си-до-ре-ми, каждая нота — шаг урока
- Наклонная бегущая строка на нотном стане, нарисованные в SVG инструменты, которые пританцовывают во время звучания, моргающие педагоги, счётчики цифр
- Всё учитывает `prefers-reduced-motion`

## Функциональность

- Возраст из ползунка и инструмент из карточки («Хочу попробовать») сразу подставляются в форму записи
- Форма пробного урока: имя ребёнка, возраст, инструмент, дата на 7 дней вперёд, слоты после школы и в выходные, имя родителя, телефон с маской, согласие родителя на обработку данных ребёнка; валидация и экран «ждём на урок»
- Иллюстрации, иконки и схема проезда — SVG, без сторонних картинок

## Стек

React 19, TypeScript, Tailwind CSS 4, Motion, Web Audio API, Vite.

## Запуск

```bash
npm install
npm run dev
```

Сборка в `dist/`: `npm run build`. Пути относительные — сборку можно выложить в любую папку, например на GitHub Pages.
